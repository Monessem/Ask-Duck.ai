Duck.ai

The extension opens Duck.ai in a new tab and automatically fills in the chat with your prompt. You pick the AI model inside Duck.ai itself — no model list to maintain here.

Automatically click "Send" after filling the prompt in Duck.ai. Turn off to review the prompt before sending (recommended — reduces bot detection).

Choose the language for Duck.ai's responses. "Auto" lets Duck.ai decide based on the prompt.

Control the text direction of Duck.ai's responses. "Auto" detects based on the response language (RTL for Arabic, Persian, Hebrew, Urdu). Code blocks stay LTR.

Test that Duck.ai is reachable from this browser.

Note: Duck.ai does not publish an official API. This extension opens Duck.ai's public web interface and fills in the chat input — exactly as you would do manually. See the About tab for details.

What data is processed?

Selected text: Sent to Duck.ai only when you trigger an action — never automatically, never to any other server.

Action choice: Processed locally; becomes part of the prompt sent to Duck.ai.

Duck.ai's terms: Once your text reaches Duck.ai, it is governed by Duck.ai's Privacy & Terms. Review them to understand how DuckDuckGo handles your input.

Permissions used

  • contextMenus — adds the right-click menu.
  • storage — stores settings and (optionally) history.
  • activeTab — accesses the current tab's selection when you invoke the assistant.
  • scripting — injects the content script on pages where it hasn't loaded yet.
  • clipboardWrite — copies prompts to the clipboard as a fallback.
  • notifications — shows optional status notifications.
  • tabs — opens and focuses the Duck.ai tab.
  • downloads — saves backup files when exporting settings.
  • host: https://duck.ai/* — required to open and interact with Duck.ai.

Shortcuts

Firefox manages keyboard shortcuts at the browser level. To customize them:
  1. Open about:addons.
  2. Click the gear icon, then "Manage Extension Shortcuts".
  3. Find "Ask Duck.ai" and edit the shortcuts.

About

What the extension does

How the Duck.ai integration works

  1. Builds a prompt from your selected text and chosen action.
  2. Opens https://duck.ai/ in a tab (reuses an existing one if open).
  3. A content script fills the chat input with your prompt and optionally clicks Send.
