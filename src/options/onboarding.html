Ask Duck.ai

Quick AI actions for any webpage — explain, translate, summarize, debug code, and more.

1

Enable the floating button

Select text on any webpage and a small Duck.ai button appears next to it. Click it to open the action menu. This is the core feature of the extension.

2

How to use

  • Select text on any webpage → the floating button appears.
  • Click the button → choose an action (translate, summarize, debug, etc.).
  • Right-click on any page or selection → use the context menu.
  • Toolbar popup → quick access to all actions and history.
  • Keyboard shortcuts → Ctrl+Shift+D (assistant), Ctrl+Shift+Y (settings).
3

Your privacy

  • No accounts, no login, no tracking.
  • Your selected text is sent directly to Duck.ai — never to our servers.
  • Conversation history is stored locally and disabled by default.
  • Works with Duck.ai's public website — no API keys, no credentials.
